# PrepAI – AI Interview & Placement Preparation Platform

PrepAI is an AI-powered web platform designed to help students prepare for campus placements and technical interviews.

## 🚀 Features

- Student Registration and Login
- Personalized Student Dashboard
- Aptitude Practice
- Coding Practice
- AI Mock Interviews
- Resume Upload and Analysis
- Company Preparation
- Career Recommendations
- Placement Readiness Score
- Progress Tracking
- AI Chatbot for Career Guidance
- Admin Dashboard

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Database
- SQLite
- SQLAlchemy

### Other Technologies
- PyPDF2
- Git & GitHub
- Render
